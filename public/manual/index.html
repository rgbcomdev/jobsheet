Part 1. Standard Process

1부. 업무일지 작성법

1. 기본 입력 항목

업무일지 시스템의 핵심 원칙은 정확한 데이터 누적입니다. 모든 임직원은 매일 퇴근 전 당일 수행한 업무 내역을 규정에 맞추어 성실히 입력해 주시기 바랍니다. 아래 가이드라인을 면밀히 숙지하여 누락 및 오입력이 발생하지 않도록 해주세요.

항목내용
시간09:00~12:00 형식
업체명클라이언트명, 사내업무는 "RGB내부"
카테고리팀별로 다름 (팀별 유의사항 참고)
단계시안 / 본작업 / 수정중 / 제작중
작업내용실제 작업 요약

2. 대시보드 화면

로그인 후 첫 화면입니다. 부서원들의 최근 작성 현황을 직관적으로 확인할 수 있습니다.

팀원 카드 클릭 → 해당 부서원의 개별 상세 일지 및 캘린더 화면으로 이동

팀원 카드 하단에 표시되는 날짜 = 마지막 최종 입력일 (신규 작성 시 자동 갱신)

가이드 참고용 스크린샷 영역 — [dashboard]

3. 신규 업체 등록

1

상단 메뉴 [통합관리] → [업체 관리] 탭으로 이동합니다.

2

업체명, 대분류, 카테고리, 해당 작업 항목, 계약 시작월 등 필수 항목을 빠짐없이 입력합니다.

3

정보 입력이 완료되면 '확정' 버튼을 클릭해 신규 업체를 시스템에 영구 등록합니다.

4

자동으로 담당자 지정 팝업창이 뜨면, 해당 업체의 실제 프로젝트 담당 사원을 선택하여 배정합니다.

※ 업체명 입력 규칙

업체명은 반드시 기업의 정식 명칭을 정확하게 입력합니다. 줄임말, 약칭, 브랜드명만 단독 표기, 앞뒤 공백·탭 삽입은 이후 통계·검색 오류의 원인이 되므로 등록 전 정식 명칭을 다시 한번 확인해 주세요.

가이드 참고용 스크린샷 영역 — [admin]

4. 캘린더 입력 순서

1

개별 캘린더에서 작성할 날짜를 마우스로 클릭하면 상세 업무 입력창이 열립니다.

2

기본 근무시간 템플릿(오전 09:00 ~ 12:00, 오후 13:00 ~ 18:00)이 사전에 자동 구성되어 나타납니다.

3

등록된 업체명 선택 후 카테고리, 세부 작업 단계, 구체적 작업 내용을 간결하게 작성합니다. 구체적 작업내용은 작업에 대한 세부내용이니 작업량을 적어주세요.

4

단계 선택 시 순서에 맞춰 시안 / 본작업 / 수정 / 제작중의 상태에 맞춰서 선택합니다.

5

하루에 여러 업체나 다양한 작업이 수행된 경우, '+ 시간대 추가' 버튼으로 행을 추가 입력합니다.

6

입력이 모두 완료되면 하단의 '저장' 버튼을 클릭하여 작성을 마칩니다.

7

완료 시 완료 버튼을 누르면 하단 프로젝트 누적현황에서 완료처리로 변경되어 전체 프로젝트에도 완료처리되어 시간이 합산됩니다.

가이드 참고용 스크린샷 영역 — [calendar-input]

※ 유의 사항 및 예외 처리 규정

일정 시간이 겹치거나 시간 전후 관계가 역전된 경우: 시스템에서 저장이 차단됩니다.

일일 총 근무 입력 시간이 15시간을 초과하는 경우: 경고 메시지만 출력되며 저장은 정상 허용됩니다.

5. 카테고리 선택 예시

카테고리는 업체명이 기준이 아닙니다. 실제 수행하여 발생한 '산출물의 본질'을 기준으로 지정해야 합니다. 따라서 한 업체라도 작업 종류가 다르다면 여러 카테고리로 나누어 기록할 수 있습니다.

Part 2. Screen Navigation

화면 연결 구조

1. 화면 연결 구조

캘린더 화면과 외부 대시보드 누적 통계 패널은 데이터베이스 상호 연결망을 가집니다. 이를 유용하게 활용할 수 있는 단축 조작 방식입니다.

[calendar-full]

★ 입력 시 꼭 확인하세요

캘린더에 프로젝트를 입력할 때 진행단계(시안/본작업/수정중/제작중)와 기업명을 정확하게 기입해야 합니다. 이 두 항목이 정확해야 프로젝트 누적현황 화면에 표시되는 단계 값도 함께 정확해지므로, 입력 직후에는 반드시 프로젝트 누적현황 화면에서 해당 단계가 올바르게 반영되었는지 한 번 더 체크해 주세요.

[project-accumulation]

대시보드에서 누적현황 수치 클릭 → 캘린더 화면으로 이동 후 해당 입력 날짜 셀이 노란색으로 반짝임

우측 상단 전체프로젝트 요약 클릭 → 해당 프로젝트의 가장 최근 마지막 작업 등록 월로 캘린더 즉시 이동

단계화면범위
①캘린더하루 원본 데이터
②프로젝트 누적현황이번 달 자동 집계
③전체 프로젝트전체 기간 자동 집계

★ 오류 수정 시 꼭 알아두세요

전체 프로젝트 화면에서 시안/본작업/수정중/제작중 카테고리 구분과 기업명이 올바르게 입력되었는지 확인하다가, 만약 기업명을 잘못 기입한 항목을 발견하면 해당 기업명을 클릭하세요. 클릭 즉시 그 항목이 입력된 날짜의 캘린더 화면으로 바로 이동하며, 그 자리에서 곧바로 수정할 수 있습니다. 전체 프로젝트 목록에서 직접 수정할 필요 없이, 원본 데이터가 있는 캘린더로 이동해 정정하는 것이 원칙입니다.

Part 3. Leave Management

연차/반차 처리

1. 연차·반차 처리

공가 및 특별 휴가를 포함하여 연차 혹은 오전/오후 반차 발생 당일에 일지 시스템을 매끄럽게 마감 처리하기 위한 규칙입니다.

①

연차 신청 선택 시: 당일 인정 시간만 사전에 자동 세팅되며 기본 틀이 비활성화 정돈됩니다.

②

이때 업체명에는 반드시 '사내업무', 작업내용에는 명확히 '연차' 또는 '반차' 문구를 본인이 직접 수동 기입해야 합니다.

③

연/반차로 차감 설정된 시간은 실 근무시간 통계 합계에는 미반영되며, 캘린더 상의 출결 증빙용으로만 깨끗하게 표시 처리됩니다.

한 사원이 두 업무를 일시적으로 겸업할 경우 → 작업내용 항목에 해당 비중을 상세히 기술해야 인정

1부 6번에서 규정한 구체적 가이드라인은 영상 제작 부서에만 제한적으로 국한됩니다. 디자인팀 등 타 제작 부서에서는 해당 복잡 단계를 강제 적용하지 않고 기존 공통 단순 단계를 준용합니다.

4. 단계 선택 — 영상팀 세부 규칙

3D영상과 촬영영상은 세부 규칙이 다릅니다. 단계 순서는 시안 → 본작업 → 수정중 → 제작중으로 고정됩니다.

※ 캘린더 자동 적용 안내

캘린더 입력 시 카테고리(3D영상 / 촬영영상)에 따라 자동으로 다른 규칙이 적용됩니다. 규칙과 다르게 입력하면 경고 문구만 표시되며, 저장 자체는 허용됩니다.

Part 6. Common Errors

2부. 자주 발생하는 오류

1. 업체명 오류 사례

수작업 검색 및 통계 누락의 가장 주된 요인입니다. 업체명 기입 시 아래의 대표 오입력 패턴을 반드시 지양해 주세요.

①
